Methodology
  • Universe — current S&P 500, MidCap 400 and SmallCap 600 constituents, ordered by risk-adjusted momentum (best first).
  • 12‑1 / 6‑1 return — price 21 trading days ago vs. price 252 / 126 trading days ago (most recent month excluded).
  • Volatility — std of daily adjusted returns over trailing 252 / 126 trading days, annualized: std × √252.
  • Vol-adjusted return — return divided by matching-window volatility. Ordering uses 0.5 × voladj12 + 0.5 × voladj6.
